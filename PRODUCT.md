# Product

## Register

product

## Users
Русскоязычные новички без опыта программирования. Пользователь хочет понимать каждую строку и постепенно переходить от упражнений к собственным программам.

Для новой мастерской пользователь подтвердил три решения: подростки и взрослые с нуля; короткие задания без таймера с постепенными подсказками; уютный стилизованный 3D-остров. Первый законченный модуль — «Мастерская механизмов»: шесть заказов от переменной до совместного запуска четырёх устройств.

## Product Purpose
Учебный сайт с теорией, примерами, проверкой понимания и практикой в игровой форме. Python становится главным последовательным курсом, остальные направления развиваются по его структуре.

## Adventure mode

По выбору пользователя добавлен уютный остров с деревней, мастерской и исследованиями. Свободная ходьба связывает короткие задания Python с изменениями мира. Первый район закрепляет четыре начальные темы; отдельный курс сохраняет 24 урока.

## Brand Personality
Спокойный, любознательный, поддерживающий. Пользователь прямо запросил приятный lofi и красивую графику Three.js.

## Anti-references
Не только игра с движением робота; не каталог обещанных, но недоступных курсов. Документация автора и исследование конкурентов не занимают место учебных материалов. Эти принципы следуют из запроса и docs/ROADMAP.md.

## Design Principles
Сначала понять, затем попробовать. Каждая строка имеет видимый результат. Ошибки объясняются без наказания. Настоящие навыки важнее XP. 3D иллюстрирует учебные понятия.

## Accessibility & Inclusion
Клавиатурная навигация, читаемый текст, мобильная вёрстка, уменьшение движения, ручной запуск и выключение музыки, запасной режим без WebGL. Эти требования продолжают существующие сценарии приложения.

## Book-based learning studio

Пользователь выбрал CodeCombat как ориентир для связи кода с происходящим на экране. Курс использует собственные объяснения по темам личной библиотеки: Укус Питона, Think Python 3e, Automate the Boring Stuff 3e. Каждый урок содержит разбор и эксперимент. Практика показывает реальную трассу Python в мастерской Искры, с воспроизведением и шагами.
