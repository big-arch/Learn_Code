## Ограничения

Это законченный базовый маршрут из 24 уроков, а не исчерпывающий курс всей экосистемы Python. Файлы внутри упражнений виртуальные, существуют только в рамках запуска; .py можно скачать. Сторонние Python-пакеты не включены.

Первичная подготовка сборки требует интернета для загрузки Pyodide (около 14 МБ). После этого Python загружается с сервера приложения. Свежий Worker создаётся для каждого запуска; первое выполнение зависит от устройства и скорости загрузки. Ограничение 6 секунд относится к выполнению после загрузки среды.

Браузерная среда предназначена для локального обучения. Она не является защищённой серверной песочницей для публичных соревнований; XP можно изменить через инструменты разработчика. Публичные аккаунты и Supabase ещё не подключены.

Docker-конфигурация обновлена, но Docker Engine в текущей среде не запускался. Автопроверки выполнены в Chromium; Safari/Firefox отдельно не проверены. Three.js-чанк около 572 кБ до gzip — предупреждение Vite, не ошибка.
