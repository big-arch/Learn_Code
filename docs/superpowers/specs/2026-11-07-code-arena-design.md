# КОД:АРЕНА — проектная концепция

## Замысел

Бесплатная русскоязычная браузерная платформа, где новичок изучает Python, C#, Go, JavaScript, HTML и CSS через короткие миссии с видимым результатом. Это не рекламный лендинг: главный экран является рабочим учебным пространством, а задания, фильтры, прогресс и Three.js-сцена работают без регистрации.

## Зачем

Новичку трудно удержать внимание на длинных видео и абстрактных упражнениях. Платформа превращает каждое действие в понятный цикл: цель → код → мгновенная реакция мира → подсказка → награда → следующая миссия. Геймификация поддерживает обучение, а не заменяет его.

## Цели

- Шесть языковых направлений с бесплатными маршрутами и программами курсов.
- Реальные интерактивные учебные миссии: команды роботу для Python, C#, Go и JavaScript, живой HTML-preview и CSS Flexbox-задача.
- Выразительная Three.js-сцена с программной геометрией, светом, орбитами и реакцией на указатель.
- Каталог с поиском и фильтрами, карта знаний, ежедневные задания, достижения и аналитика прогресса.
- Сохранение XP, выполненных миссий, черновиков и настроек в localStorage.
- Управление с клавиатуры, нативные диалоги, live-region, reduced motion, пауза WebGL вне экрана.
- Адаптивный интерфейс и автономная сборка `dist/bundle.html`.

## Не входит в этот прототип

- Серверные аккаунты, синхронизация между устройствами, общий рейтинг и настоящее сообщество.
- Полноценные компиляторы Python, C# и Go в браузере. Для них используется честно обозначенная учебная симуляция команд и проверки, а не утверждение о выполнении кода.
- Платные сертификаты, подписки, реклама, скрытые ограничения и механики наказания за пропущенный день.
- Исчерпывающий обзор буквально всех учебных сайтов. Исследование репрезентативно и опирается на официальные источники.

## Анти-цели

- Красивый, но пустой лендинг с неработающими кнопками.
- Бесконечная лента, навязчивые попапы, случайные награды и соревнование вместо освоения навыков.
- Тяжёлая 3D-сцена, которая мешает читать, работать на телефоне или экономить заряд.

## Рассмотренные подходы

1. **Статичный сайт-витрина.** Быстро и дёшево, но не демонстрирует саму платформу и не отвечает запросу на вовлекающее обучение.
2. **Полнофункциональный frontend-прототип — выбран.** React + TypeScript + Vite + Three.js дают рабочий продукт, локальное состояние и автономную демонстрацию без стоимости backend-инфраструктуры.
3. **Сразу production-платформа с backend и удалёнными исполнителями кода.** Избыточно для первой версии, требует аккаунтов, безопасных sandbox-сред, серверов и эксплуатационного бюджета.

Решение принято автономно в соответствии с режимом работы без уточняющих вопросов.

## Визуальная система

Тёмный графитовый фон, кислотно-лаймовый основной акцент, холодный циан и тёплый коралловый для разных состояний. Без фиолетовых градиентов и одинаковых скруглённых карточек. Заголовки — Unbounded, интерфейс — Manrope, код — JetBrains Mono, с системными fallback. Асимметричная композиция, тонкие координатные линии, технические подписи и контрастные редакционные заголовки.

## Основные экраны и поведение

- **Главная:** Three.js-остров, текущая миссия, шесть направлений, цель недели, достижения.
- **Курсы:** поиск, фильтры по языку и уровню, карточки, детальная программа и запуск урока.
- **Карта:** связанные узлы навыков и понятные зависимости.
- **Арена:** выбор языка, редактор, подсказки, запуск проверки, визуальный результат, XP и следующий шаг.
- **Прогресс:** активность, навыки, полученные достижения, сброс локальных данных с подтверждением.
- **Исследование:** сравнительные карточки и ссылки на официальные источники.

## Объём контента и исполнение

Для каждого из шести направлений создаётся одна полностью проходимая миссия с редактором, проверкой, подсказкой, наградой и сохранением результата. Программы курсов содержат по четыре содержательных модуля и обозначают дальнейший маршрут, но не выдаются за десятки уже наполненных видеоуроков. JavaScript использует тот же безопасный ограниченный симулятор команд, что Python, C# и Go; произвольный код не выполняется через `eval` или `new Function`.

## Технические решения

React 18 + TypeScript, Vite, Three.js, Lucide icons, CSS с design tokens. Данные курсов локальные и типизированные. Нативный `<dialog>` для программы курса, command palette и подтверждений. Three.js останавливается при `prefers-reduced-motion`, ручной паузе, скрытой вкладке и пропуске контента браузером; fallback — IntersectionObserver. WebGL-ошибка показывает статичную схему, не ломая обучение.

## Критерии готовности

- `npm run build` проходит без TypeScript-ошибок.
- Все основные кнопки приводят к реальному действию.
- Можно открыть миссию, изменить код, получить ошибку и подсказку, затем успешно завершить её; XP и прогресс сохраняются после перезагрузки.
- Фильтры, поиск, программа курса, карта, прогресс и исследование работают.
- Сайт проверен в браузере на desktop и mobile; нет горизонтального переполнения и критических ошибок консоли.
- Сформирована production-сборка и один автономный HTML-файл.
