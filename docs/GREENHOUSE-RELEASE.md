# Учебный портал: первый выпуск

17 ноября 2026. Learn Code / КОД:АРЕНА.

## Что доступно

На главной появился «Мой учебный путь»: основы Python → «Умная теплица» → закрепление на новых данных. «Продолжить обучение» выбирает незавершённый шаг. Глава также доступна из курса Python, поиска и страницы прогресса. Предыдущие уроки, музыка, остров и мастерские сохраняются. Самостоятельные проекты из пункта 4 исключены пользователем; их код и материалы не менялись.

| Занятие | Действие | Проверяемая идея |
| --- | --- | --- |
| Прочитай сигнал | Предсказать результат | Сравнение даёт True/False |
| Найди точную границу | Изменить датчик и код | Разница между < и <= |
| Собери две ветки | Упорядочить строки | if, else и отступы |
| Поймай лишнюю каплю | Исправить ошибку | Проверка граничного значения |
| У насоса два условия | Выбрать правило | and, or и пустой бак |
| Проветри теплицу | Написать код | Перенос сравнения на температуру |
| Два независимых решения | Управлять двумя устройствами | Независимые условия вместо ошибочного elif |
| Не доверяй сломанному датчику | Исправить порядок проверок | Диапазон, if/elif/else |

У каждого занятия есть цель, объяснение на русском, исполняемый пример, задача, три подсказки и объяснение результата. Пример не засчитывает прохождение. Проверки исполняют программу на нескольких входных данных и принимают разные корректные решения. Фиксированные ответы, неверные типы и распространённые логические ошибки не проходят проверки.

Three.js показывает реальные значения `water`, `fan` и `mode`: полив, вентилятор, влажную почву и сигнал ошибки. Значения продублированы текстом. Датчики можно менять и снова запускать код. Сцена не расходует отрисовку в скрытой вкладке и вне экрана; уменьшение движения и режим без WebGL поддержаны. Редактор сохраняет автоподсказки и увеличивается вместе с кодом.

## Прогресс и повторение

- Восемь первых прохождений дают суммарно 460 XP. Повторный запуск и повторение не увеличивают награду.
- Повторение меняет пороги с 35% / 28°C на 45% / 30°C и имеет отдельный черновик.
- Навыки показывают «Знакомлюсь», «Решил с подсказкой», «Решил самостоятельно», «Повторил на новых данных». Предыдущие прохождения без истории попыток не выдаются за самостоятельные решения.
- После неудачной последней попытки или перерыва появляется предложение повторить. Интервал: три дня после первого решения, семь после самостоятельного повторения. Достижения сохраняются.
- События содержат ID и версию занятия, тип действия, вариант, результат, факт помощи и время. Хранится до 16 событий на занятие и до 512 всего; успешные решения и открытые подсказки сохраняются при сокращении истории.
- Новые данные синхронизируются существующим механизмом с проверкой ревизии. Старая открытая вкладка без поля `learning` сохраняет историю и данные теплицы в облаке. Явный сброс удаляет их, устаревшее устройство не восстанавливает старую эпоху.

Сценарный блок «Разберём вместе» объясняет типичные ошибки и конкретную неуспешную проверку. Генеративный ИИ в этом выпуске не подключается. Полноценный интерфейс автора курсов и остальные новые игровые главы относятся к следующим этапам; этот выпуск добавляет проверяемый формат материалов и автоматические проверки публикации.

## Материалы и выпуск новых занятий

Контент: `src/data/greenhouse.json`. Формулировки, примеры, решения, подсказки и варианты повторения хранятся отдельно от интерфейса. `LIMIT` и `HEAT` заменяются параметрами текущего варианта. ID не менять при редакторской правке; при изменении учебных требований повышать `version` и проверить сохранённый прогресс.

`npm run check:content` проверяет структуру и полноту материалов. `npm run test:learning` выполняет примеры и решения в реальном Pyodide, проверяет ошибки, границы, альтернативные решения и правила хранения истории. Проверки включены в GitHub QA и публикацию Pages. Перед выпуском нужны также ручная проверка текста и браузерное прохождение.

Для новой установки Supabase после `server/learn-code-cloud.sql` и `server/learn-code-device-sync.sql` применить `server/learn-code-learning.sql`. В существующий проект изменения уже внесены через миграции. Таблицы и настройки других приложений не менялись.

## Проверка перед публикацией

- TypeScript, lint, проверка контента и production-сборка прошли.
- 277 автоматических проверок: обучение 30, существующий Python 139, мир 8, редактор 9, игры 19, механизмы 22, практикум 20, облако 12, SQLite API 18 (включая родительский тест).
- 37 браузерных проверок главы: все восемь занятий, пример без награды, неправильные ответы, помощь, повторение, отсутствие повторных XP, сохранение после перезагрузки, остановка Python, автоподстройка редактора и ширины 1440/1024/768/390.
- 13 браузерных проверок синхронизации и доступности: два изолированных браузера с имитацией авторизованного RPC; код, подсказки, прохождение и повторение; живая анимация и prefers-reduced-motion; автоподсказки; выход из редактора клавиатурой; реальное выполнение Python без WebGL.
- 15 регрессионных браузерных проверок старых мастерских, практикумов, импорта, конфликтующих черновиков, выхода и мобильного аккаунта. Отправка почты в них имитируется, реальные письма не отправлялись.
- Реальная Supabase: проверка в транзакции с откатом — валидация событий, анонимный RPC по личному коду, чтение/запись, защита от старого клиента, конфликт ревизии, сброс и запрет прямого чтения приватных строк. Тестовые профили этой проверки не остаются в базе.

Предупреждение сборщика о крупных существующих общих чанках остаётся; новая глава вынесена в отдельную загрузку. Аудит Supabase не нашёл новых проблем этой миграции. Информационное сообщение [RLS без политик](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy) для приватной таблицы ожидаемо: доступ только через проверяющий личный код RPC. Существующее предупреждение [защиты паролей Auth](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) относится к общему проекту; настройки Auth не менялись.

Браузерные сценарии: `qa/greenhouse-browser.mjs`, `qa/greenhouse-sync-browser.mjs`. Они создают и закрывают собственные контексты. SQL-проверка: `qa/learning-database.sql`, всегда с `ROLLBACK`.

Фактическая публикация и проверка публичной версии фиксируются отдельно в `.cache/GREENHOUSE-PUBLICATION-QA.md` после завершения GitHub Actions.
