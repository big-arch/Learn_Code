## Регрессии движка

12 эталонных решений принимаются, 12 незавершённых стартовых решений отклоняются. Ещё 17 случаев: пустой код, непарные кавычки, выход за поле, склеенные команды, неподдерживаемый бесконечный цикл, огромное число повторений, неверный отступ, лишние шаги до той же цели, команды в комментариях, чрезмерная длина, C# без точки с запятой, отсутствие цикла в уроке циклов, CSS-комментарии, перекрытие CSS-объявлений, чужой селектор, !important и HTML вне main.

## Исправленные причины ошибок

- Регулярные выражения искали команды внутри произвольных строк. Теперь команда должна занимать строку и соответствовать учебной грамматике.
- Кристалл можно было достигнуть длинным обходом вопреки условию четырёх шагов. Длина теперь проверяется.
- CSS в комментарии засчитывался; последнее объявление не учитывалось. Сцена и проверка используют один браузерный CSS-парсер.
- Результат старого запуска оставался после изменения кода. Теперь проверка и маршрут сбрасываются.
- Вводные задания изображали владение целым языком. Прогресс теперь относится к двум доступным миссиям.
- Исторические завершения попадали в «текущую неделю». График пересчитывается по completedAt при загрузке.
- Устаревшие Clock/PCFSoftShadowMap вызывали предупреждения Three.js. Время берётся из performance.now, тени используют PCFShadowMap.
- Плавная прокрутка и сдвиг кнопки при наведении мешали стабильному нажатию в длинном уроке. Убраны.
- Добавлены favicon, ограничение исходника, порядок записи SQL и явный статус недоступного сохранения.

## Ограничения

- Есть 12 вводных миссий, а не полные курсы.
- Ограниченная учебная грамматика не является полноценным Python/JS/C#/Go. Нестандартная форма for и вложенные циклы не поддерживаются.
- CSS-урок применяет display и justify-content прямого селектора #pond; это не универсальный CSS-редактор.
- Ключ браузерного профиля не заменяет аккаунт. Нет синхронизации между устройствами и серверной защиты рейтинга XP.
- HTML изолирован sandbox и CSP; произвольные скрипты не исполняются.
- Three.js вынесен в отдельный файл около 545 КБ (около 135 КБ gzip); Vite сообщает предупреждение о размере chunk.
- В Node.js 22.18 node:sqlite отмечен экспериментальным. API и перезапуск проверены на установленной версии.
- Docker и чистая установка на другой ОС пока не подтверждены. GitHub Actions будет выполнять сборку, lint и API-проверки.
