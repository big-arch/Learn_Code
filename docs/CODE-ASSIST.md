# Подсказки при написании кода

Подсказки подключены к курсу Python, дополнительным видеопрактикам, диалогам острова, Арене и текстовому режиму мастерской. Языки: Python, JavaScript, C#, Go, HTML и CSS. В режиме блоков программа остаётся доступной только для чтения.

В мастерской поле кода автоматически растёт вместе с текстом и уменьшается при удалении строк. Это работает и для программы из блоков, и при ручном вводе. Высота пересчитывается при изменении ширины экрана и загрузке шрифтов; вертикальной прокрутки внутри поля нет. Проверены 24 строки из блоков, вставка 45 строк, сокращение текста, автодополнение и перенос длинных строк на телефоне — 10 браузерных проверок без ошибок.

- Начни вводить команду: `pri` предложит `print()`, `fo` — шаблон цикла. В меню есть объяснение на русском.
- Стрелки выбирают вариант, Tab или Enter вставляют его. На телефоне можно нажать на вариант.
- Ctrl Space или кнопка «Подсказки» открывают список вручную. Переключатель «Авто» отключает автоматическое меню в текущем редакторе.
- В шаблонах выделяется место для своего значения. Например, после вставки цикла можно сразу изменить число повторений.
- Скобки и кавычки закрываются автоматически. Выделенный текст можно обернуть в пару. Повторное закрытие пропускает готовый символ; Backspace удаляет пустую пару.
- Enter сохраняет отступ и добавляет четыре пробела после Python `:` и открывающих скобок. Tab / Shift Tab меняют отступ строки или выделения.
- Escape закрывает список. Escape, затем Tab позволяют выйти из редактора клавиатурой.
- Ctrl Z отменяет локальное редактирование, Ctrl Shift Z / Ctrl Y возвращают его. Ctrl Enter запускает код.

Подсказки не появляются внутри строк и комментариев. В CSS-мастерских доступны соответствующие режиму свойства и значения, в заданиях робота — учебные команды `hero.move`, `Hero.Move` или `hero.Move` и циклы. К Python-подсказкам добавляются имена переменных из текущего текста.

Это локальный словарь и шаблоны, без внешнего AI и отправки кода в сторонний сервис. Это не языковой сервер: проверки типов, полной семантики и предложений всех установленных библиотек нет. Вставленный шаблон нужно заполнить самостоятельно. История отмены хранится в памяти текущего редактора, ограничена 100 шагами и сбрасывается при внешней замене текста, в том числе облачной синхронизации. Черновики сохраняются прежним механизмом прогресса.

## Проверки

- `npm run test:editor`: 9 проверок замены токенов, шаблонов, лексического контекста, языков, парных символов и отступов.
- `qa/code-assist-checks.mjs`: 33 проверки в отдельном браузерном контексте: клавиатура, отмена/повтор, выделения, запуск настоящего Python, прохождение CSS-уровня, сохранение, мобильное меню, API робота и HTML. Проверка ошибки отправки использует имитацию ответа, письма не отправляет.
- Регрессия: 55 браузерных проверок игровых уровней и 10 проверок аккаунтов с имитацией Auth/RPC, включая обновление уже открытого редактора.

## Что выяснено о BookWords

Проверены локальные файлы `C:/Users/big-a/Documents/Программирование/bookwords-app/script.js`, `CLOUD_SYNC.md`, `index.html` и опубликованный `https://big-arch.github.io/bookwords-app/script.js`.

В текущем BookWords кнопка «Создать код» генерирует личный код синхронизации. `getUser()` возвращает этот код как идентификатор, `push()` и `pull()` записывают/читают снимок в `bookwords_sync` по `sync_key`. При подключении не вызывается отправка OTP-письма. Оба приложения используют один проект Supabase, но разные механизмы входа и отдельные таблицы. В исходниках BookWords остаётся обработчик старого callback, что не делает текущую кнопку входом по email.

Пользователь ранее выбрал для Learn Code вход по почте, поэтому он сохранён. Работа синхронизации BookWords не подтверждает исправность SMTP. Последняя проверенная отправка Learn Code завершилась SMTP 535 (отклонены данные отправителя). В этой доработке SMTP и BookWords не менялись, новые реальные письма не отправлялись. Для HTTP 5xx в Learn Code добавлено понятное сообщение о сбое сервиса входа и необходимости проверки журналов владельцем сайта.
