## Python: «Почта острова»

1. Собрать правильный порядок строк настоящей программы.
2. Исправить ошибку сложения строки и числа.
3. Выбрать маршрут посылки условием, включая граничный вес.
4. Отобрать тяжёлые посылки из списка циклом или генератором.
5. Исправить функцию, перепутавшую `print` и `return`.
6. Собрать диспетчер станции: функция тарифа, общая стоимость, отбор и отчёт.

Исполнение идёт в существующем Python Worker/Pyodide. Пошаговая почтовая лента показывает реальные значения переменных и списков. Доступны пауза, шаг назад/вперёд и итог. Автовоспроизведение учитывает настройки движения; скрытая вкладка ставит его на паузу. Для длинных программ итог доступен отдельно от первых 120 записанных шагов.

Формулы проверяются на других данных, поэтому одного готового ответа недостаточно. Альтернативные решения, включая `sum` и генераторы списков, принимаются. Учебный пример не заменяет черновик и не даёт XP. Каждая тема связана с соответствующей главой основного курса.

## HTML/CSS: «Сайт почтовой станции»

1. Смысловая разметка заголовка и абзаца.
2. Список почтовых маршрутов.
3. Селектор, цвета и внутренние отступы.
4. Распределение окон выдачи через Flexbox.
5. Равные ячейки через Grid.
6. Микроанимация карточки: `transform`, `transition`, наведение и уменьшение движения.
7. Итоговая страница с разметкой, оформлением и доступной кнопкой.

Оба файла, HTML и CSS, сохраняются одним черновиком. Предпросмотр обновляется после ввода. Проверка использует DOM, вычисленные стили и геометрию браузера, поэтому эквивалентные цвета и CSS-записи допустимы. На телефоне наведение демонстрируется кнопкой. Готовую страницу можно скачать в HTML, Python-проект в `.py`.

Предпросмотр предназначен для учебной разметки и обычных CSS-правил, без JavaScript и загрузки внешних ресурсов. Неразрешённые HTML-элементы и обработчики удаляются в инертном шаблоне. Iframe запускается без разрешения скриптов, форм и навигации; CSP запрещает внешние ресурсы. Это формат данного тренажёра, а не универсальная веб-IDE.

## Общий учебный интерфейс

- Маршрут показывает доступные темы, формат задания, выполненные шаги и итоговый проект.
- На широком экране теория и критерии, редактор и результат видны одновременно. На телефоне идут последовательно с быстрыми переходами.
- Три последовательные подсказки, объяснение ошибок Python, повторные попытки без штрафа.
- За все 13 заданий начисляется 900 XP; повторы не увеличивают награду.
- Новые задания подключены к общему прогрессу, гостевому хранению, SQLite и существующему механизму синхронизации аккаунта.
- В 24 прежних уроках Python цель видна во время чтения, а критерии проверки доступны до запуска решения.

## Проверки

- `npm run test:practice`: 20 тестов настоящего Python, включая все решения, примеры, незавершённые заготовки, альтернативные входы и эквивалентное решение проекта.
- `npm run test:api`: 17 тестов, включая сохранение новых достижений и двух файлов проекта.
- `qa/practice-checks.mjs`: 46 проверок основного маршрута в браузере.
- `qa/practice-edge-checks.mjs`: 17 проверок ошибок, отмены, длинной трассы, альтернативного CSS, защиты предпросмотра и переходов.
- `qa/practice-motion-checks.mjs`: 7 проверок воспроизведения, паузы, уменьшения движения и переходов на телефоне.
- Регрессия: 55 проверок прежних игр, 33 автодополнения, 15 аккаунтов с подменой Supabase. Проверено обновление открытого Python-редактора и обоих файлов веб-проекта с другого тестового устройства. Реальные письма не отправлялись; прежняя проблема SMTP остаётся отдельной задачей.
- Новые Python-тесты включены в QA и публикацию GitHub Pages.
