# Предложение: Learn Code как профессиональный учебный портал

Дата: 17 ноября 2026. Направление развития одобрено пользователем, **кроме пункта 4 — самостоятельных проектов**. Первый выпуск реализует связный маршрут и восемь занятий «Умной теплицы», навыки, повторение, сценарную помощь и проверку контента. Объём и QA описаны в [GREENHOUSE-RELEASE.md](GREENHOUSE-RELEASE.md). Остальные главы и полноценная система редактирования материалов остаются дальнейшими этапами. Исходное предложение основано на коде 09a73d9 и открытых материалах учебных платформ.

## Идея продукта

Русскоязычная школа программирования для подростков и взрослых с нуля. Человек проходит путь от понимания отдельной строки до самостоятельной программы, которую умеет объяснить, проверить и изменить. Уютный остров, музыка и персонажи сохраняют характер сайта. Учебный маршрут связывает теорию, игры, упражнения и проекты.

Проверяемый результат базового Python: ученик пишет небольшую программу по описанию, обрабатывает неправильный ввод, сохраняет данные, разбивает код на функции, пишет проверки и объясняет свои решения. Трудоустройство и профессиональный уровень не обещаются за прохождение вводного курса.

## На что уже можно опереться

- 24 урока Python охватывают ввод, типы, ветвления, циклы, коллекции, функции, исключения, модули, файлы, JSON, классы и тесты. Есть финальное задание.
- Работают выполнение Python в браузере, запись шагов, подсказки, автодополнение, игровые задания Three.js, практикумы Python и HTML/CSS.
- Есть облачная синхронизация по личному коду, разрешение конфликтов черновиков и гостевой профиль. Почтовый вход требует отдельного завершения настройки SMTP; последняя проверенная ошибка относится к 10 ноября, повторной проверки сегодня не было.
- Навигация содержит одновременно курс, практикум, приключение, мастерскую и арену. Их нужно связать понятным следующим действием внутри маршрута.

Глубину обучения следует оценивать по самостоятельным решениям и проектам. Сам факт прохождения урока и начисленные XP пока не описывают, насколько уверенно человек владеет навыком.

## Предлагаемый учебный процесс

Для новой темы: короткое объяснение → предсказание результата → пример с разбором → упражнение с поддержкой → самостоятельная задача → применение в проекте → повторение позже. Объём адаптируется к теме; не требуется помещать все шаги в одно занятие.

Каждый урок получает явную цель, необходимые знания, пример, типичные ошибки, несколько принимаемых способов решения и проверяемые критерии. Подсказки раскрываются постепенно. Тесты охватывают обычные и граничные данные; неверный ответ объясняется на конкретном примере.

Для сложных тем нужны промежуточные задания. Например, перед классами ученик должен уметь группировать данные словарём и выделять повторяющиеся действия в функции. Книги остаются источниками оригинальных русскоязычных объяснений, экспериментов и ссылок для углубления.

## Главные изменения

### 1. Единый маршрут и личный учебный экран

Главный экран показывает последнее занятие, ближайшую цель, тему для повторения и текущий проект. Кнопка «Продолжить» ведёт к конкретному незавершённому шагу. Предлагаемая навигация: «Мой путь», «Курсы», «Практика», «Проекты», «Профиль»; справочник доступен из урока и поиска. Игровые механики открываются из соответствующих тем и остаются доступными для свободной практики.

Игра и обычная задача используют общую модель навыков. Для ученика, предпочитающего спокойную рабочую среду, тот же учебный результат доступен без прогулки по острову.

### 2. Разнообразные форматы практики

| Формат | Действие ученика | Что проверяется |
| --- | --- | --- |
| Предсказание | До запуска объяснить результат | Понимание порядка выполнения |
| Отладка | Найти причину неисправности, исправить и проверить | Работа с ошибками |
| Сборка программы | Упорядочить строки, затем написать аналог самостоятельно | Структура решения |
| Эксперимент | Изменить условие или данные и объяснить последствия | Причина и следствие |
| Свободное решение | Написать программу по требованиям | Перенос навыка |
| Ревью | Сравнить рабочие решения по читаемости и надёжности | Качество кода |

Это общие инструменты для будущих курсов. Существующие сборка строк и отладка становятся частью последовательной системы упражнений.

### 3. Игровой мир с учебными последствиями

Идеи для новых занятий:

- **Умная теплица:** условия управляют поливом по датчикам; ошибки видны в состоянии растений. Ученик затем пишет ту же логику для обычного набора данных.
- **Архив наблюдений:** списки, словари и JSON помогают восстановить повреждённые записи; требуется обработать отсутствующее поле и неправильное значение.
- **Диспетчерская маршрутов:** алгоритм ищет путь и сравнивает варианты. Это продвинутый модуль после базовых коллекций и функций.
- **Магазин острова:** веб-направление создаёт карточки, адаптивную сетку и взаимодействие; SQL-направление выбирает товары и считает остатки.

Three.js показывает значения, события и последствия запуска. Управление воспроизведением, крупные подписи и текстовый результат остаются доступными. Пользователь может уменьшить движение или работать в облегчённом режиме.

### 4. Самостоятельные проекты

**Исключено пользователем из работ.** Перечисленные ниже идеи не реализуются в этом выпуске; существующие проекты не изменяются.

Предлагаемые проекты Python: мини-версия BookWords с поиском и повторением слов, планировщик с JSON-хранилищем, анализатор CSV-данных, игра с сохранением состояния. Для веба: личная страница и небольшое приложение с формой, фильтрацией и доступным интерфейсом.

Каждый проект содержит техническое задание, этапы, критерии приёмки и список самостоятельных улучшений. Итог: исходники, инструкция запуска, тесты и краткое объяснение автора. Затем появляется отдельный переход к работе на своём компьютере, Git и публикации репозитория.

### 5. Прогресс по навыкам и повторение

Хранить события попыток, использованные подсказки, версии заданий и результаты проверок. Различать «познакомился», «решил с помощью», «решил самостоятельно» и «подтвердил на новой задаче». Это наблюдения об обучении, а не точная оценка способностей человека.

Предлагать повторение после ошибок и спустя время. Не обнулять достижения при пропуске дня. При добавлении новой версии задания сохранять старое прохождение и объяснять, что именно предлагается повторить.

### 6. Помощник, который поддерживает обучение

Сначала качественные сценарные подсказки и объяснения распространённых ошибок. Затем опциональный ИИ-наставник, которому доступны текст текущего задания, код и результаты проверки. Действия: объяснить строку, задать наводящий вопрос, привести отдельный пример, помочь интерпретировать ошибку.

Зачёт задания определяют тесты и критерии. Ответ ИИ не заменяет проверку. Подключение модели требует отдельного решения о сервисе, стоимости, передаваемых данных и лимитах; для основного курса оно не обязательно.

### 7. Основа для регулярного выпуска курсов

Добавить редактор учебных материалов: черновик, предпросмотр, публикация, история версий. Автоматически проверять эталонные решения, примеры и намеренно ошибочные решения, которые должны отклоняться. Перед выпуском главы проводить редакторскую проверку объяснений и пробное прохождение новичками.

Сохранить React, TypeScript и Three.js. Продолжить использовать Supabase/PostgreSQL; развести учебный контент, попытки, навыки, проекты и черновики. Для нового способа учёта прогресса подготовить миграцию существующих достижений. Исправить почтовый вход, восстановление доступа и спроектировать явную привязку личного кода к аккаунту с подтверждением владельца.

Начальные задания продолжат выполняться в браузере. Многофайловые серверные проекты и полноценные C#/Go потребуют отдельно спроектированного изолированного исполнения с ограничением времени, памяти, сети и доступа к секретам. Docker может быть частью развёртывания, но одного контейнера недостаточно для защиты публичного выполнения чужого кода. Платную инфраструктуру выбирать после определения нужного сценария и нагрузки.

## Порядок работ

1. **Первый выпуск:** новый личный учебный экран, связанный маршрут и одна эталонная глава из 6–8 занятий; четыре формата практики, одна новая игровая сцена, один мини-проект и повторение. Проверить на 5–10 новичках. Параллельно завершить надёжное подключение и восстановление профиля.
2. **Python как основной курс:** переработать остальные главы по проверенному шаблону, добавить промежуточные и самостоятельные проекты, карту навыков и редактор материалов. Число занятий определять по учебным целям и результатам пробных прохождений.
3. **Расширение:** полноценный путь HTML/CSS/JavaScript, затем SQL; отдельные глубокие направления C# и Go после проверки архитектуры исполнения. ИИ-наставник и совместная работа добавляются по необходимости.

Критерии готовности первого выпуска: новичок самостоятельно находит следующий шаг; понимает условие; может объяснить ошибку; решает похожую новую задачу без копирования; создаёт работающий мини-проект; продолжает на другом устройстве без потери кода. Время загрузки и понятность интерфейса проверяются на согласованных телефонах и компьютерах. Проба на 5–10 людях выявляет проблемы, но не доказывает эффективность курса для любой аудитории.
