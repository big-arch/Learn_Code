# QA приключения, 7 ноября 2026

Проверки выполнены в Windows / Node.js 22.18 и Chromium.

## Текущая версия: история и чёткость

- TypeScript, production build и oxlint проходят.
- 116 Node-тестов прошли (включая родительские): 94 Python, 14 API, 8 движение/поиск пути. Проверены допустимые приветствия и отклонение постороннего вывода.
- 36 браузерных проверок приключения прошли: маршрут Мира → Тим → Боб → Лея с автоматическим открытием разговора, точный пользовательский пример `print("привет")`, автозачёт без дополнительной кнопки, неверный ответ, закрытие до/после успеха, события, карта и Искра, пересечение моста, финал.
- Проверены защита от повторного начисления XP, сохранение 310 XP в SQLite, восстановление после перезагрузки и режим без WebGL. Необработанных ошибок JavaScript нет.
- Мобильный экран 390×844: кнопка продолжения доступна, горизонтальной прокрутки нет. Визуально просмотрены desktop и mobile.
- Имена NPC отображаются текстом HTML, canvas рендерится с повышенным разрешением и ограничением бюджета пикселей. Изменены материалы, освещение, вода и детализация теней.

Тесты используют новые браузерные контексты; пользовательский прогресс не очищается. API-тесты используют временную базу.

При выпуске предыдущей версии также прошли 68 проверок старой арены и 24 проверки Python Studio. В текущем изменении эти разделы не менялись; повторно проверен весь маршрут приключения.
