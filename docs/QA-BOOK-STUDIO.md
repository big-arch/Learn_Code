# QA: уроки по книгам, анимация и музыка

7 ноября 2026. Windows, Node.js 22.18, Chromium.

- 121 Node-тестов прошли: Python, API SQLite, движение на острове. Новые проверки трассировки подтверждают переход строки '7' → числа 7 → результата 17, итерации цикла, локальные параметры функций, исключения и ограничение записи 120 шагами без остановки программы. Наблюдение не вызывает пользовательский __repr__, в том числе внутри коллекций.
- 155 браузерных проверки прошли: 68 арена, 24 Python Studio, 36 приключение, 27 новый экран обучения.
- Новый набор qa/book-studio-checks.mjs проверяет материалы всех 24 уроков, эксперимент с ответом, источник чтения, размер шрифтов, запуск примера без изменения черновика/XP, шаги и подсветку, паузу, скорость, уменьшение движения, WebGL fallback и мобильный экран 390×844.
- Музыка проверена через Web Audio analyser: есть ненулевой звуковой сигнал; после паузы он затухает. Проверены шесть композиций, автосмена, настроение, следующий трек и случайный выбор. Исправлен конфликт запланированного плавного перехода с паузой.
- Существующие задания, SQL-сохранение, восстановление, защита от повторных XP и остановка бесконечного цикла прошли регрессию.
- TypeScript/production build, oxlint и git diff --check проходят. Сохранилось предупреждение сборщика о Three.js-чанке более 500 КБ.

Тестовые браузерные профили изолированы. Пользовательский прогресс не очищался. Визуально просмотрены desktop и mobile. Firefox, Safari, Docker и длительное фоновое воспроизведение на реальном телефоне не проверялись.
