## Как работает мастерская

Python записывает состояние после выполненных строк: номер, локальную область, значения переменных и накопленный вывод. Интерфейс воспроизводит эту запись; повтор анимации не запускает программу и не начисляет XP. Перемещения Искры условно иллюстрируют ввод, обработку и вывод; они не являются отдельными командами Python.

- Запуск своего кода показывает его выполнение, включая реальные повторения циклов и исключения.
- Учебный пример помечен отдельно, не меняет черновик и не завершает задание.
- Пауза, следующий шаг, повтор и скорость позволяют рассмотреть значения.
- Номер выполнявшейся строки подсвечивается в редакторе.
- Записываются первые 120 шагов, до 8 переменных и последние 2000 символов вывода на шаг. При усечении есть уведомление; полный вывод сохраняет прежний лимит 12000 символов.
- Временные файлы по-прежнему изолированы на каждый запуск. Ограничение выполнения 6 секунд сохранено.
- Без WebGL доступны текстовые шаги и состояния. Уменьшение движения выключает автоматическое воспроизведение; шаги можно включить вручную.

## Музыка

Шесть процедурных композиций с разными последовательностями аккордов, мелодиями и темпом: Тёплый причал (74 BPM), Дождь в мастерской (66), Ночной трамвай (84), Бумажные фонари (78), Тихая бухта (60), Орбита сна (56). Последние две без ударных. Аранжировка меняется по разделам; автосмена после 32 тактов выбирает следующую композицию текущего настроения. Запуск только по действию пользователя. Сохраняются выбранная композиция и громкость.

Это синтезированная музыка, не записи сторонних исполнителей и не стриминг Spotify.
