# Мастерская механизмов

Новый законченный игровой модуль находится в разделе **Мастерская → Python · Мастерская механизмов**. Это первый модуль обновлённого направления: для подростков и взрослых, начинающих с нуля, с заданиями на 5–10 минут без таймера и уютным изометрическим островом. Время — ориентир, ограничений нет.

## Учебный маршрут

| Заказ | Понятие Python | Видимый результат | XP |
|---|---|---|---:|
| Первый огонёк | Имя, значение, присваивание | Три секции фонаря загораются | 70 |
| Энергия из кристаллов | Выражения и умножение | Кристаллы питают маяк | 80 |
| Насос для сада | Приоритет арифметических операций | Меняется уровень воды | 90 |
| Турбина | Строка, целое число, `int()` | Код управляет вращением лопастей | 100 |
| Табличка | Соединение строк | Надпись появляется на острове | 90 |
| Открытие станции | Небольшой проект и `print()` | Все четыре устройства работают вместе | 150 |

Каждый заказ включает историю, объяснение, исполняемый пример с другими исходными данными, вопрос на понимание, самостоятельный код и три последовательные подсказки. После успеха открывается следующий заказ. Итог — 580 XP и завершение станции; повторные решения не начисляют XP повторно. Пройденные заказы доступны для экспериментов.

## Как работает игра

- Настоящий Python выполняется существующим Pyodide в отдельном Web Worker. Формулы проверяются также на другом наборе исходных значений, поэтому подстановка одного готового ответа не заменяет вычисление.
- `power`, `water`, `speed`, `label` управляют фонарём, насосом, турбиной и табличкой. Сцена отражает выбранный шаг реального выполнения, рядом всегда доступны точные значения и типы.
- Можно поставить запись на паузу, перейти на шаг назад/вперёд, повторить её или сразу увидеть результат. При ограничении записи первыми 120 шагами итоговая кнопка показывает настоящий финальный снимок переменных.
- Учебный пример сохраняет черновик ученика и не даёт XP. Зависшую программу можно остановить. Редактирование или переход на другой заказ отменяет старый запуск.
- Редактор поддерживает существующее автодополнение, скобки, отступы, `Ctrl+Enter` и автоматическое увеличение высоты.
- 3D построено в Three.js из собственных геометрических объектов: настил, мастерская, инструменты, маяк, бак, ветряк, растения, житель, лодка. Нет заимствованных игровых моделей или текстур.
- Устройства выбираются мышью на сцене или обычными кнопками. При недоступности WebGL остаётся пульт, а все задания продолжают работать. Настройки уменьшения движения отключают вращение и автоматическое воспроизведение.
- На телефоне есть переходы между сценой и редактором. Прежние 16 уровней доступны во вкладке **Другие мастерские**; отдельный Python-курс из 24 уроков сохранён.

Черновики и достижения включены в существующее хранение: браузерный гостевой профиль, локальный SQLite API, синхронизация аккаунта. Новые таблицы Supabase не нужны. Проверка синхронизации в этом обновлении использовала два изолированных браузерных профиля и подменённый ответ Supabase; реальная доставка email не проверялась и ранее обнаруженная проблема SMTP этим модулем не исправляется.

## QA

- `npm run lint`, `npm run build`, `npm run build:pages`.
- `npm run test:mechanisms`: 22 проверки настоящим Python — решения, незавершённые заготовки, примеры, неверные типы, подставленные ответы, границы показателей и трасса.
- `npm run test:api`: 16 тестов с новым сохранением всех заказов и черновика в SQLite.
- `qa/mechanisms-checks.mjs`: 38 проверок в браузере — весь маршрут, шаги, подсказки, награды, перезагрузка, мобильный экран, отмена, длинная трасса, резерв без WebGL.
- Регрессия прежних игр: 55 браузерных проверок; автодополнение: 33; аккаунты и конфликт черновиков: 12, включая передачу нового Python-черновика и достижения между двумя тестовыми устройствами.
- Новый набор автоматических проверок включён в GitHub QA и в workflow публикации Pages.

Это одна новая игра с шестью заказами, а не шесть отдельных игр. Следующие самостоятельные механики можно строить поверх того же исполнения Python, сохранения и подсказок.
