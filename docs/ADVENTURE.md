# Остров Тихой бухты

Первый играбельный уровень браузерного приключения. Выбранный пользователем стиль — уютный остров, деревня, мастерская и исследования. Собственные модели создаются в Three.js: это оригинальная стилизованная 3D-сцена, без заимствования графики CodeCombat.

## Что готово

Герой свободно ходит по острову. Камера следует за ним, ноги анимируются, дома, деревья, ворота и река ограничивают движение. Маршрут по нажатию на землю обходит препятствия. Есть мини-карта, масштаб и журнал.

| Житель | Тема Python | Видимое последствие |
|---|---|---|
| Мира | print, строка | В мастерской загорается свет |
| Тим | Переменные | Поднимаются деревянные ворота |
| Боб | Числа, умножение | Появляется настил из шести досок |
| Лея | input, int, вычисление | Зажигается маяк и появляется луч |

Диалог включает объяснение, пример, задачу, редактор, выполнение настоящим Python и подсказку. Проверка должна пройти до применения результата к миру. Всего 310 XP; повторное решение не начисляет награду. Состояние объектов восстанавливается из завершённых заданий в SQLite/localStorage. Позиция героя при новом входе возвращается к причалу.

## Управление

- WASD / стрелки — свободно идти. Сначала выбери игровую сцену.
- Нажатие на землю — пройти по доступному маршруту.
- E или кнопка разговора — общаться с ближайшим жителем.
- «Идти к цели» — найти маршрут к текущему заданию.
- Экранные стрелки — управление на телефоне.
- Масштаб — приблизить или отдалить камеру.
- Esc — закрыть диалог. При редактировании кода ходьба приостанавливается.
- При потере WebGL задания остаются доступны через журнал.

## Связь с курсом

24 урока Python — отдельный последовательный курс с теорией, вопросами и практикой. Приключение закрепляет первые четыре темы, но не засчитывает весь урок за один игровой ответ. Сейчас доступны четыре сюжетных задания, а не 24 готовых игровых уровня.

## Дальнейший маршрут — предложения

| Район | Учебная глава | Идеи игровых задач | Статус |
|---|---|---|---|
| Тихая бухта | Первые строки | Приветствие, ключ, мост, маяк | Реализовано |
| Сад и теплица | Строки, логика, условия | Полив по влажности, таблички, сортировка урожая | Идея |
| Лесопилка | Циклы и списки | Робот собирает ресурсы, повторяет маршрут, складывает инвентарь | Идея |
| Мастерская | Коллекции и функции | Рецепты, поиск предметов, команды помощника | Идея |
| Порт и библиотека | Ошибки, модули, файлы | Журнал экспедиции, обработка неверных заказов | Идея |
| Новая экспедиция | JSON, классы, тесты, проект | Управление поселением и проверяемый диспетчер задач | Идея |

Следующий сильный шаг: бот-помощник с командами Python и подсветкой выполняемой строки. После проверки первого уровня на новичках — добавить уникальные модели жителей, скелетные анимации, звуки шагов и событий, постепенное открытие карты. Lofi-плеер уже доступен во время путешествия.

## Техническая структура

- src/adventure/world.ts — правила движения, коллизии и поиск пути.
- src/adventure/IslandWorld.tsx — Three.js, камера, анимации, ввод и визуальные последствия.
- src/adventure/QuestDialog.tsx — теория, редактор, проверки и награда.
- src/views/AdventureView.tsx — HUD, журнал, мини-карта и связь с сохранением.
- src/data/adventure-quests.json — сценарии и проверки Python.
