# Игровая мастерская Тихой бухты

Добавлено 8 ноября 2026 года. Открыть: меню **Мастерская** или кнопка на главной странице.

## Реализовано

16 собственных уровней, 4 мастерские, всего 1200 XP:

- **Лодочная бухта** — 4 задачи по Flexbox: конец оси, центр, распределение, две оси.
- **Сад дождя** — 4 задачи по Grid: столбцы, строки, диапазоны линий, span.
- **Теплица** — 4 задачи на CSS-селекторы и чтение HTML: класс, id, атрибут, nth-child.
- **Маршруты Искры** — 4 маршрута с командами и циклами. Блоки создают редактируемый код на Python, JavaScript, C# и Go; выполнение показано в существующей Three.js-сцене.

Каждый уровень содержит краткую теорию, понятную цель, подсказку, проверку, возможность повторить и кнопку следующего открытия. Все уровни доступны для самостоятельного выбора. Последовательность постепенно усложняется, обязательной блокировки уровней нет. После четвёртого уровня можно перейти в следующую мастерскую. Общий прогресс, черновики и XP сохраняются существующим механизмом браузер + SQLite. Повторное прохождение не начисляет XP второй раз.

CSS применяется к реальным DOM-элементам. Проверка Flexbox/Grid сравнивает положение и размер объектов с целью, а не строку ответа. Поддерживаются эквивалентные решения. Разрешён только небольшой набор свойств и значений соответствующего урока; пользовательский CSS не вставляется в глобальную таблицу стилей. Селекторы ищут растения внутри поля, неверный синтаксис получает объяснение.

Робот использует ограниченный учебный API движения и циклы for. Это не произвольное выполнение JS/C#/Go и не замена полноценному Python-курсу. Можно переключаться между блоками и текстом; язык меняется в режиме блоков. В текстовом режиме доступен тот же синтаксис команд, что в существующей Арене. При отсутствии WebGL сохраняется 2D-режим. Уменьшение движения учитывает настройку сайта и системы.

На телефоне цель показана перед игровым полем; редактор расположен ниже. Кнопки, подсказки и сборка блоков доступны без перетаскивания. Нижняя навигация прокручивается горизонтально.

## QA

- `npm run lint` — успешно.
- `npm run build` — TypeScript + Vite, успешно; остаётся предупреждение о размере общего JS-пакета, не ошибка сборки.
- `npm run test:games` — 19 проверок генерации и выполнения четырёх языков, ограничений CSS и неверных программ.
- `npm run test:api` — 15 проверок, включая новые идентификаторы, черновики и SQLite.
- `npm run test:python` — 139 проверок текущего курса и видеопрактик.
- `npm run test:world` — 8 проверок острова.
- `qa/game-lab-checks.mjs` — 57 браузерных проверок: все уровни, неправильные решения, эквивалентный Grid, четыре языка, сохранение, перезагрузка, отсутствие дублирования XP, мобильные задачи и отсутствие JS-исключений.

Дополнительно в браузере пройдены 9 проверок: отмена анимации редактированием без начисления XP, запрет повторного запуска во время движения, Ctrl+Enter, мобильная цель, переход через прогресс и рабочий 2D-режим без WebGL. Итого 66 браузерных проверок.

Браузерный сценарий запускается с Vite на 5175 и отдельным тестовым SQLite API на 4184, в новом одноразовом контексте браузера. Рабочий профиль пользователя не очищается. Снимки игрового поля сохраняются в `qa/game-lab-*.png` и исключены из Git.

## Где находится реализация

- `src/data/game-lab.json` — все задания и примеры решений.
- `src/lib/gameLab.ts`, `src/lib/gameLabEngine.ts` — модели, генератор команд, разбор CSS и проверка геометрии.
- `src/views/GameLab.tsx`, `src/views/game-lab.css` — игровой экран и собственная графика.
- `src/lib/storage.ts`, `server/index.mjs` — регистрация миссий в общем прогрессе.

Возможное продолжение: самостоятельная HTML-мастерская с построением интерфейсов; новые алгоритмические маршруты с условиями и функциями; редактор собственных головоломок. Эти режимы пока не реализованы.
