# КОД:АРЕНА — Learn Code

Игровой тренажёр программирования на русском языке. Продолжение проекта KIMI: React + TypeScript + Vite + Three.js, локальный Node.js-сервер и SQLite.

## Открыть на другом компьютере

**[Запустить КОД:АРЕНУ в браузере](https://big-arch.github.io/Learn_Code/)** — установка не нужна. Ссылка работает независимо от домашнего компьютера.

В онлайн-версии доступны курс Python, остров и игровая мастерская. Кнопка **Войти** отправляет ссылку на email; после входа прогресс синхронизируется через Supabase. В аккаунте можно перенести гостевой прогресс текущего браузера. Без входа сохраняется отдельный гостевой профиль на устройстве. Локальная SQLite-база не публикуется. Первое выполнение Python загружает среду интерпретатора с сайта. Подробности: [вход и синхронизация](docs/EMAIL-SYNC.md).

Публикация происходит через `.github/workflows/pages.yml` после изменений в `main`. Сборка для сайта: `npm run build:pages` → `dist-pages`. Путь `/Learn_Code/` учитывается для JS, CSS и Python Worker. Обычная `npm run build` сохраняет локальную версию с SQLite.

## Что работает

- **Практикум**: 13 оригинальных упражнений и два проекта, «Почта острова» на Python и «Сайт почтовой станции» на HTML/CSS. Перестановка строк, отладка, пошаговая лента, живой предпросмотр и сравнение с образцом. [Учебные подходы и QA](docs/LEARNING-PATHS.md).

- **Мастерская механизмов**: шесть последовательных заказов на настоящем Python, четыре управляемых кодом устройства на 3D-острове, теория, примеры, подсказки и пошаговый разбор. [Описание и QA](docs/MECHANISM-WORKSHOP.md). Прежние 16 уровней доступны через «Другие мастерские».

- **Приключение «Остров Тихой бухты»**: свободная ходьба, жители, четыре задания Python и изменения 3D-мира. [Управление и план развития](docs/ADVENTURE.md), [QA приключения](docs/QA-ADVENTURE.md).

- Новый визуал: тёмная обсерватория, тёплые акценты, светлая поверхность для чтения.
- Базовый Python-курс: 24 готовых урока, 6 глав, теория → вопрос → самостоятельный код.
- Вывод, переменные, типы, условия, циклы, коллекции, функции, исключения, модули, файлы, JSON, классы и тесты.
- Финальный проект: диспетчер задач экспедиции.
- Настоящий Python через Pyodide в отдельном Web Worker. input(), стандартная библиотека, виртуальные файлы, понятные результаты проверок и скачивание .py.
- Three.js-обсерватория с вращением камеры и спутниками глав; после запуска кода — объёмные контейнеры переменных и текстовые значения.
- Фоновая синтезированная lofi/ambient-музыка: ручной запуск, пауза, громкость.
- Справочник Python заменяет прежнее «Исследование». [Объяснение раздела](docs/RESEARCH.md).
- Сохранены 12 вводных игровых миссий для Python, JavaScript, C#, Go, HTML и CSS.
- XP без повторного начисления, черновики, SQLite, мобильная версия и резерв при недоступности WebGL.

Python-курс покрывает базу до небольшого самостоятельного проекта. Другие направления пока имеют по две вводные миссии с ограниченным учебным интерпретатором; их полные курсы остаются в плане развития.

## Запуск

Нужен Node.js 22.18+ и pnpm 10.11.0.

```powershell
cd C:\Users\big-a\Documents\KIMI_Lear_Code
corepack enable
corepack prepare pnpm@10.11.0 --activate
pnpm install --frozen-lockfile
npm run build
npm start
```

Открыть **http://127.0.0.1:4174**. В уже подготовленной папке достаточно двойного щелчка по **start-local.cmd**. Окно сервера нужно оставить открытым.

Для разработки: в одном терминале `npm start`, во втором `npm run dev -- --port 5175`. Открыть http://127.0.0.1:5175. Vite проксирует /api на SQLite-сервер.

Сервер по умолчанию слушает только 127.0.0.1. Настройки окружения: PORT, HOST и DB_PATH. По умолчанию база — `data/learning.sqlite`; она создаётся автоматически по `server/schema.sql`.

## Docker

```powershell
docker compose up --build -d
```

Адрес: http://127.0.0.1:4174. Том learning-data сохраняет базу между перезапусками. Команда `docker compose down` сохраняет том; параметр -v удаляет данные. Docker-сборка не проверена в текущей среде: Docker Engine не запущен.

## Проверки

```powershell
npm run lint
npm run build
npm run test:api
npm run test:python
npm run test:world
```

API-тесты запускают отдельный сервер на 4197, создают временную SQL-базу, проверяют изоляцию, валидацию, сохранение и перезапуск.

`qa/browser-checks.mjs` экспортирует функцию `async(page)` для Playwright. В ней проверки 12 миссий, ошибочного ввода, XP и мобильной версии. qa/studio-checks.mjs проверяет Python-курс, SQL-восстановление, Worker и плеер. Нужны запущенные dev/API-серверы. Для отдельного запуска можно установить Playwright без изменения зависимостей проекта: `npm install --no-save --package-lock=false playwright`, затем `npx playwright install chromium` и `node qa/run-browser.mjs`. Тест использует отдельный браузерный контекст.

Фактические результаты и ограничения: [QA нового курса](docs/QA-STUDIO.md), [отчёт первой версии](docs/QA.md).

## Как хранятся данные

Случайный ключ профиля сохраняется в браузере; сервер хранит только SHA-256 этого ключа и JSON состояния в SQLite. Это локальные профили без регистрации. Не отправляйте ключ другим людям. Удаление всех данных браузера удаляет и ключ доступа к прежнему профилю. Для резервирования базы остановите сервер и скопируйте папку data целиком.

При восстановлении локальная копия имеет приоритет; SQL используется, если локальная копия отсутствует, но ключ профиля сохранился. Это не межустройственная синхронизация. При недоступном сервере изменения остаются в браузере; следующий запуск или изменение прогресса повторит сохранение. Не предусмотрены публичные рейтинги и защита от самостоятельного изменения XP.

Для публичного сервиса рекомендованы Supabase Auth + PostgreSQL с RLS, HTTPS и серверная проверка решений. В публичной версии подключены Supabase Auth и отдельная таблица прогресса с RLS; локальный гостевой режим сохраняет SQLite. [Варианты архитектуры и идеи](docs/ROADMAP.md).

## Структура

- src/data — курсы, миссии, учебные объяснения.
- src/lib/missionEngine.ts — ограниченный интерпретатор и проверка.
- src/components/RobotWorld.tsx — Three.js-поле и 2D-резерв.
- src/state — прогресс, восстановление, очередь сохранения.
- server — HTTP API, статический сайт, SQLite.
- qa — интеграционные и браузерные проверки.

При первой сборке npm run build автоматически загружает среду Python, проверяет SHA-256 и включает файлы в dist. Для подготовки отдельно: npm run prepare:python. Нужен интернет при подготовке; в готовом приложении Python загружается с того же сервера и кэшируется. Файлы внутри упражнений виртуальные и очищаются между запусками.

Шрифты Google Fonts необязательны: при отсутствии сети используются системные. Музыка синтезируется локально. [Внешние компоненты и лицензии](docs/THIRD_PARTY.md).
